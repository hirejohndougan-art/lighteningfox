Swiftiron

A web browser engine built from scratch in Rust.

Getting around

  • Click the address bar (or press Ctrl+L) and type a URL or a search.
  • Tabs: Ctrl+T new, Ctrl+W close, Ctrl+Tab next, Ctrl+Shift+T reopen. Drag tabs to reorder them.
  • Bookmarks: Ctrl+D or the ☆. History: Ctrl+H.
  • Back and forward: the ← → buttons, or Alt+Left and Alt+Right. Reload: F5.

Built in

  • Modern pages: flexbox, grid, floats, tables, sticky headers, transforms, web fonts
  • JavaScript (Boa engine) with fetch, forms, history and storage; React, Vue and jQuery run
  • Text in any script: kerning and ligatures, Chinese, Japanese, Arabic, Hebrew, Hindi
  • Privacy: third-party cookies blocked, tracking tags removed from links, Global Privacy Control
  • Light on memory: sleeping background tabs, and drawing with the graphics card when there is one
