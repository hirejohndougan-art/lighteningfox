LighteningFox

A web browser engine built from scratch in Rust.

Getting around

  • Click the address bar (or press Ctrl+L) and type a URL or a search.
  • Scroll with the mouse wheel, arrow keys, Space and Page Up/Down.
  • Click links. Use the ← → ↻ buttons, or Alt+Left, Alt+Right and F5.

What works so far

  1. HTML parsing into a DOM tree
  2. CSS parsing, selectors and the cascade
  3. Block and inline layout with word wrapping
  4. Text, backgrounds and borders painted by our own rasterizer
  5. JavaScript through the Boa engine: DOM, events, timers
  6. Images: PNG, JPEG, GIF, WebP, and data: URLs
  7. CSS variables, calc(), and styled inline boxes

Not yet: flexbox and grid, forms, tabs.
